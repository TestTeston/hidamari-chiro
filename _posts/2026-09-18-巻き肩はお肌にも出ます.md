脇の下や\
鎖骨のあたりが、\
ときどきズキンと痛む——\
\
そんな覚えは\
ありませんか。\
\
肩こりとは\
少し違う場所なので、\
不思議に思われる方が\
多いところです。

**原因は、わりとシンプルです**\
**肩が開いていない。**\
\
それだけのことが\
多いのです。\
\
スマホ。\
パソコン。\
前かがみの仕事。\
\
現代の生活は、\
放っておくと\
**肩がどんどん内側へ狭まっていきます**。\
\
いわゆる巻き肩です。\
\
肩が内に入ると、\
胸の前側が\
縮んだままになります。\
\
その状態が続くと、\
鎖骨のまわりが\
詰まってきます。

**ここに、流れの道が通っています**\
**耳の下から首筋を通って、鎖骨の外へ抜けていく**——\
\
体には、\
そういうリンパの流れの道が\
あります。\
\
胸の前が縮んで\
鎖骨まわりが詰まると、\
**この流れが滞ります**。\
\
美容の世界で\
「デコルテが大事」と\
言われるのを\
聞いたことが\
あるかもしれません。\
\
あれは、\
おしゃれの話だけでは\
ありません。\
\
**ここが詰まると、肌荒れやニキビが出やすくなる**からです。\
\
顔にばかり\
手をかけているのに\
どうも調子が出ない、\
という時。\
\
**原因が、肩の位置にある**ことが\
あるのです。

**ケアは、開くこと**\
やることは\
難しくありません。\
\
**鎖骨の下側の筋肉を、胸の中心から肩口に向かって伸ばして開く。**\
\
指の腹で、\
内から外へ。\
\
お風呂に入った時に、\
**鎖骨の下を軽くマッサージ**してあげてください。\
\
強く押す必要は\
ありません。\
さするくらいで\
十分です。\
\
そのあと、\
両腕を後ろに引いて\
胸を開く。\
\
それだけで、\
呼吸まで\
少し深くなります。

**肌は、体の状態が出る場所です**\
**肌の調子は、心の疲れと体の疲れ、その両方から出てきます。**\
\
眠れていない。\
気を張り続けている。\
ずっと前かがみでいる。\
\
そのどれもが、\
めぐりまわって\
顔に出ます。\
\
化粧品を変える前に、\
一度、\
**肩の位置を疑ってみてください。**

小川
