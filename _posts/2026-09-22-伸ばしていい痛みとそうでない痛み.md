---
title: 伸ばしていい痛みと、そうでない痛み
date: 2026-09-22

腰が痛い時。\
\
**動かしたほうがいいのか、安静にすべきか。**\
\
これで迷われる方は、\
とても多いです。\
\
先日、\
痛いところをグイグイ押さないで、\
という話を書きました。\
今日はその続きです。

**一つの目安があります**\
**動かしている最中に痛むかどうか。**\
\
ここを見てください。\
\
ストレッチや軽い動きの\
最中は痛くないのに、\
**ある方向にひねった時だけ痛い**。\
\
そういう場合は、\
筋肉が傷ついているというより、\
**縮こまって固まっている**ことが\
多いのです。\
\
このタイプの痛みは、\
**時間をかけて、じわーっとゆっくり伸ばしてあげれば楽になります**。\
\
痛いけれど、\
ゆっくり伸ばしていけば\
伸びる。\
\
伸びれば、\
楽になる。

逆に、\
**勢いをつけて反動で伸ばす**。\
**気合いを入れてガーンとやる**。\
\
これをやると、\
今度は本当に\
傷つけてしまいます。\
\
**焦らず、ゆっくり。**\
\
固まったものを解くのに、\
力は要りません。\
**要るのは、時間です。**

**動かさないと、どんどん狭くなります**\
痛いと、\
つい体を\
動かさなくなります。\
\
すると、\
**痛くない範囲の動きだけに偏っていきます**。\
\
その範囲の外は\
使われなくなり、\
やがて\
できなくなっていく。\
\
**動かさない → 固まる → もっと動かせない。**\
\
これが\
痛みの悪循環です。\
\
かといって、\
無理な動きで\
余計に痛めるのも怖い。

**そこで、もう一つの目安です**\
**「これまでの人生でできていた動き」は、できるはずです。**\
\
今まで普通に\
やってきた動作。\
\
靴下をはく。\
上の棚に手を伸ばす。\
振り返る。\
\
そういう\
当たり前だった動きが\
できなくなっているなら、\
**それは戻せる可能性が高い**ということです。\
\
新しく\
難しい体操を\
覚える必要は\
ありません。\
\
**当たり前にしてきた動きを取り戻すところから**\
始めてください。

**まとめると**\
動作の最中に痛まないなら、\
ゆっくり伸ばしていい。\
\
勢いはつけない。\
\
そして、\
**昔できていた動きの範囲まで**を\
目安にする。\
\
それ以上のことを\
急にやろうとしないこと。\
\
痛みがあると\
どうしても\
焦ってしまいますが、\
**体がゆるむのに必要なのは、力ではなく時間です。**

小川
