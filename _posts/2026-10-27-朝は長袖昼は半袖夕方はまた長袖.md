「朝は寒いから\
長袖を着るんです。\
でも昼前には暑くなって\
半袖に着替えて。\
夕方には、\
また寒いんですよ」\
\
最近、\
患者さんから\
よく聞く話です。

**スポーツの秋、のはずなのに**\
朝晩が涼しくなって、\
ようやく\
動きやすい季節に\
なりました。\
\
ところが、\
皆さんから聞くのは\
**「動けない」**\
という話ばかりです。\
\
「頭では、\
動いたほうがいいって\
分かっているんです。\
でも、\
気分が乗らなくて」\
\
これは、\
怠けているわけでは\
ありません。

**体は、一日じゅう働いています**\
朝の冷え。\
昼の暑さ。\
夕方の冷え。\
\
この温度の変化に、\
体は\
一日じゅう\
対応しています。\
\
寒ければ縮こまり、\
暑ければゆるむ。\
\
**それを一日に何度も繰り返して、知らない間に疲れている**\
のです。\
\
「スポーツの秋なのに、\
なぜか動けない」\
\
その理由は、\
**体が温度差への対応で手一杯だから**\
だと思います。

**夏の疲れも、まだ残っています**\
今年の夏は、\
長く、\
暑かった。\
\
暑さで固まった体が、\
まだ\
戻りきっていないところに、\
朝晩の冷えが\
重なっています。\
\
最近は、\
**気持ちのいい春と秋が、ずいぶん短くなりました。**\
\
体のほうも、\
切り替えが\
追いつかないのだと思います。

**がんばるより、整える**\
こういう時期に\
「運動しなきゃ」と\
がんばる必要は\
ありません。\
\
それよりも、\
**一日の合間に、ちょっと整える時間**を\
作ってみてください。\
\
・朝、着替えのついでに、腕を大きく回す\
・ラジオ体操の「深呼吸」のように、ゆっくり息を吸って胸を広げる\
・夜は湯船に浸かって、縮こまった体をゆるめる\
\
**縮こまったら、ゆるめてあげる。**\
\
それを\
こまめに\
繰り返すだけで、\
体はずいぶん\
楽になります。

**着る物と同じです**\
暑ければ脱いで、\
寒ければ羽織る。\
\
服は\
こまめに\
調整しているのに、\
体のほうは\
そのまま、\
ということが\
多いのです。\
\
**体にも、一枚羽織らせる、一枚脱がせる。**\
\
そんなつもりで、\
この季節を\
過ごしてみてください。

小川
