これから\
12月、1月。\
\
寒さで\
**体が固まってくる方が、増えてくる季節**\
です。\
\
固まった関節を\
どう考えればいいか。\
最近、患者さんに\
こんな例えで\
お話ししています。

**ファンデーションのパフ**\
お化粧に使う、\
あのスポンジを\
思い浮かべてください。\
\
濡れているうちは、\
ふわっと\
柔らかい。\
\
でも、\
乾いてしまうと\
**パキパキに固くなります。**\
\
固まった関節は、\
極端に言うと\
あんな感じです。

**水をかけても、弾いてしまう**\
乾いたパフを\
柔らかく戻すには、\
水を含ませて\
揉んであげれば\
いい。\
\
ところが、\
カチカチの状態で\
上から水を流しても、\
**表面で弾いてしまって、なかなか染み込みません。**\
\
少しずつ\
揉みながら\
水を入れていく。\
\
**関節も同じで、必要なのは「動き」です。**\
\
体の中の水分や\
栄養も\
もちろん大事です。\
でも、\
動かしてあげないと\
そこに届いていかない。

**錆びついたドアと同じ**\
錆びついたドア、\
という例え方も\
します。\
\
しばらく\
開けていなかったドアは、\
最初は\
ギギッと\
重たい。\
\
でも、\
何度か\
開け閉めしているうちに、\
ちゃんと\
動くようになります。\
\
**70代、80代の方でも、動かしてあげれば、体はちゃんと動くようになります。**

**一番よくないのは、何もしないこと**\
固まった関節は、\
動かすと\
痛いことが\
あります。\
\
痛いから\
動かさない。\
動かさないから\
もっと固まる。\
\
**体は、使わないでいると「ここは使わなくていいんだ」と、使わない方向へ変わっていきます。**\
\
世の中では\
「痛いなら、\
やめておきましょう」\
となることが\
多いと思います。\
\
ひだまりの考えは、\
少し違います。\
\
**痛みと相談しながら、少しずつ動かす。**\
\
どこまで\
攻めるかは、\
ご自身の\
感覚で\
かまいません。\
やりすぎて\
痛みが残るのは\
よくないので、\
「ちょっと\
きついかな」\
くらいで\
止めてください。

**気張らず、焦らず、少しずつ**\
ラジオ体操のような\
動きで\
十分です。\
\
腕を\
上まで\
上げきる。\
胸を\
大きく\
開く。\
背中を\
反らす。\
\
**普段の生活で使わない角度ほど、固まりやすい**\
ので、\
そこを\
一日に\
一回でも\
通ってあげる。\
\
乾いたパフに\
少しずつ\
水を含ませるように。\
\
それが、\
**冬の体をカチカチにしない一番の近道**\
です。

小川
