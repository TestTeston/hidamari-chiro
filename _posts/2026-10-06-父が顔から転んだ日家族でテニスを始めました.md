うちの父が、\
甥っ子について行って、\
**顔から突っ転んで怪我をした**ことが\
あります。\
\
手が、出なかったのです。\
\
それを見て、\
家族で\
「**これは運動しなあかんわ**」と\
なりました。

**同じような話を、患者さんからも伺いました**\
ご近所の方が、\
**普通に歩いていて、何かに引っかかって前に倒れた**。\
\
やはり\
顔から行ってしまって、\
唇もおでこも\
大変なことになったそうです。\
\
ご本人が、\
こうおっしゃっていたと\
聞きました。\
\
「**あんなところで、なぜ転ぶんだろう**」

**答えは、はっきりしています**\
**足が上がっていない**のです。\
\
ほんの数センチ。\
\
若い頃なら\
何ということもなかった段差に、\
つま先が\
引っかかる。\
\
そして、\
**とっさに手が出ない。**\
\
だから、\
顔から行きます。\
\
手が出るのも、\
足が上がるのも、\
**当たり前ではなくなっていきます。**

**いちばん怖いのは、ここです**\
転ばれた方は、\
みなさん\
こうおっしゃいます。\
\
**「上げているつもりだった。」**\
\
つもりだった、というところが\
怖いのです。\
\
自分では\
ちゃんとできているつもりでも、\
できていない。\
\
**自分の歩き方は、自分からは見えません。**\
\
見えないから、\
気づけないのです。

**では、どうやって気づくか**\
うちは、\
父が転んだのをきっかけに、\
**甥っ子・弟夫婦・両親・私の六人**で、\
月に一度くらい\
テニスをするようになりました。\
\
やってみて、\
気づいたことが\
二つあります。

**一つめ。一人では、続きません**\
「家で自分でやるとなると、なかなかできない」\
\
本当に、その通りだと思います。\
\
**両親と私の三人だけだったら、たぶん続いていません。**\
\
甥っ子がいて、\
弟夫婦がいて、\
六人集まるから\
成立しています。\
\
**集団の力は、これはデカいです。**\
\
お金を払ってどこかへ通うのが\
理にかなっているのも、\
同じ理由だと思います。\
払ったからには、行く。\
それだけで続きます。

**二つめ。みんなでやると、自分の現状が分かります**\
これは、\
思いがけない発見でした。\
\
甥っ子を見て\
「これくらいの力加減か」。\
\
両親を見て\
「**これくらいにしないといけないな**」\
「あまり遠くへは球を逃がせないな」。\
\
そうやって見ているうちに、\
自分についても\
分かってきます。\
\
「**俺も、相当やり直さなあかんな**」\
\
**一人で鏡を見ていても、これは分かりません。**\
\
現状確認としては、\
いちばんいいチェックかも\
しれません。

**上手である必要は、ありません**\
テニスでなくても\
構いません。\
\
散歩でも、\
ボール遊びでも、\
体操でも。\
\
**誰かと一緒にやる**というところだけ、\
残してみてください。\
\
足が上がっているかどうかは、\
自分よりも\
**隣にいる人のほうが、よく見えています。**

小川
