朝晩が、\
ずいぶん涼しくなってきました。\
\
夏のあいだ、\
暑さで運動を休んでいた——\
\
そういう方が、\
今ごろになって\
「そろそろ再開しようかな」と\
動き出されます。\
\
とても、いいことです。\
ただ、\
一つだけお願いがあります。

**いきなり全力で投げないでください**\
野球をされている方には、\
私はいつも\
こうお伝えしています。\
\
久しぶりのキャッチボールで、\
**一球目から本気で投げない**。\
\
**少しずつ、様子を見ながら。**\
\
これは\
野球に限った話では\
ありません。\
\
久しぶりのウォーキング。\
久しぶりのジム。\
久しぶりのゴルフ。\
\
どれも同じです。

**気持ちのほうは、休んでいません**\
やっかいなのは、\
ここです。\
\
**休んでいたのは体だけで、気持ちは休んでいません。**\
\
頭の中には、\
前に動けていた頃の感覚が\
そのまま残っています。\
\
「これくらいは、いけたはず」\
\
ところが体のほうは、\
**休んだぶんだけ、正直に鈍っています。**\
\
この**ズレ**が、\
秋にいちばん多い\
痛めかたです。

**一球目は、置きにいっていいんです**\
では、どうするか。\
\
**最初の何回かは、わざと物足りないくらいで止める。**\
\
これに尽きます。\
\
「まだいけるな」と\
思うところで\
やめておく。\
\
物足りないまま\
帰ってきた日は、\
翌日、\
体が軽いはずです。\
\
その軽さを\
二度、三度と\
確かめてから、\
少しずつ上げていく。\
\
それで\
十分間に合います。

**せっかく、いい季節です**\
暑さで動けなかったぶん、\
これから\
体を戻していける時期です。\
\
**急ぐ必要は、まったくありません。**\
\
一球目を丁寧に投げた方だけが、\
冬まで\
続けられます。

小川
