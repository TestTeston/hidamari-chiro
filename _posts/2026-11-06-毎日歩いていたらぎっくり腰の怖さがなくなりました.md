「前みたいな、\
ぎっくり腰になりそうな感じが、\
もうないんです。\
毎日歩いているから\
ですかね」\
\
長く通ってくださっている\
患者さんに、\
そう言われました。

**忙しくても、来ない**\
その方は、\
今も仕事が忙しく、\
体は\
かなり\
酷使しているそうです。\
\
以前なら、\
こういう時期には\
腰に\
「来るぞ」という\
嫌な感じがあった。\
\
それが、\
今はない。\
\
**「あの怖さがないのは、本当にありがたいです」**\
\
そう話してくれました。

**特別なことは、していません**\
その方が\
続けているのは、\
**毎日歩くこと。**\
それだけです。\
\
筋トレでも、\
特別なストレッチでも\
ありません。\
\
以前、\
[歩くのはカロリーを減らすためじゃありません](/blog/20260911.html)\
という話を\
書きました。\
\
今日のお話は、\
**それを実際に続けた方に、何が起きたか**\
です。

**体に「耐久力」がついてくる**\
日頃から\
体を動かす癖があると、\
体には\
**耐久力**が\
生まれてきます。\
\
少し無理をしても、\
すぐには\
崩れない。\
\
忙しい時期に\
体を酷使しても、\
持ちこたえてくれる。\
\
ぎっくり腰は、\
ある日突然\
来るように見えます。\
でも本当は、\
**持ちこたえる力が、少しずつ減っていった先に**\
来るものです。

**次の日に来るのは、バロメーター**\
その方は、\
家庭菜園も\
されています。\
\
「やっている時は楽しくて、\
無心でできるんです。\
でも、\
次の日くらいから\
足腰にきますね」\
\
これは、\
**普段どれだけ体を使えているかの、バロメーター**\
です。\
\
次の日に来るのは、\
悪いことでは\
ありません。\
**やれる体を作っていく、途中の合図**\
だと思ってください。

**いちばん遊べる時期のために**\
その方が、\
こんなことを\
教えてくれました。\
\
「65歳から75歳が、\
人生のゴールデンエイジ\
らしいですよ」\
\
子育ても終わって、\
時間にも\
少し余裕ができる。\
\
「でも、\
その頃には\
体がうまく動かない、\
っていう人が\
多いんですよね」\
\
だからこそ、\
**動くうちに、動いておく。**\
\
楽しみたい時に\
楽しめる体を、\
今から\
作っておく。\
\
毎日歩くことは、\
その\
いちばん手軽な\
準備だと思います。

小川
