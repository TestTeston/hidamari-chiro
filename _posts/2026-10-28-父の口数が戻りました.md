先日、\
[うちの父が顔から転んだ話](/blog/20261006.html)を\
書きました。\
\
あれをきっかけに、\
家族六人で\
テニスを始めた、\
という話です。\
\
今日は、\
その後の父の\
話です。

**父が、仕事に出るようになりました**\
少し前から、\
父が\
外へ働きに\
出るようになりました。\
\
ちょうど\
時間を持て余していた\
タイミングだったのも\
あって。\
\
ちょっとした\
お小遣いをもらいながら、\
**知らない人と話す機会**が\
できました。

**口数が、戻ってきました**\
そうしたら、\
**父の口数が、戻ってきた**のです。\
\
前に比べて、\
いろいろ\
話してくれるように\
なりました。\
\
夫婦で\
旅行に出かけたり、\
スポーツに\
行ったり。\
\
**よく動いてくれています。**\
\
顔から転んだ日のことを\
思い出すと、\
ずいぶん\
変わったなあと\
思います。

**ただし、好き嫌いが激しくなりました**\
一つだけ、\
困ったことが\
あります。\
\
最近、\
**好き嫌いが激しくなった**のです。\
\
先日、\
久しぶりに\
ビーフシチューを作ってもらったら、\
中に\
パプリカが\
入っていました。\
\
美味しいのに。\
\
**父は、パプリカだけ全部残していました。**\
\
「子どもかよ」と、\
家族で\
突っ込んでいます。\
\
まあ、\
それくらい言えるほど\
元気だということに\
しておきます。

**外に出ると、戻ってくる**\
体を動かすこと。\
人と話すこと。\
\
どちらも、\
家の中に\
こもっていると\
少しずつ\
減っていきます。\
\
減っていることには、\
自分では\
なかなか\
気づけません。\
\
**体も気持ちも、外に出ると戻ってくるもの**\
なのかもしれません。\
\
父を見ていて、\
そう思いました。\
\
パプリカのほうは、\
戻ってくる気配が\
ありませんが。

小川
