date: 2026-11-03

「ズボンの丈が、\
右だけ短いんです。\
裾が、\
片方だけ余るの」\
\
患者さんに、\
そう言われました。\
\
衣替えで\
長ズボンを出してきて、\
気づいた方も\
いらっしゃるかもしれません。

**脚の長さが、変わったわけではありません**\
その方は、\
「脚の長さが\
違ってきたのでは」と\
心配されていました。\
\
実は、\
**骨の長さそのものが、左右で変わることはまずありません。**\
\
変わるのは、\
**骨の「位置」**\
です。

**骨盤は、ねじれるように回ります**\
骨盤は、\
前に出たり、\
後ろに引っ込んだり、\
ねじれるように\
回転します。\
\
片方の骨盤が\
前にねじれて出てくると、\
その側の脚が\
引っ張られて、\
**反対側が短く見える**\
のです。\
\
その方の場合、\
左の腰骨が\
だいぶ下がっていました。\
\
差は、\
指一本あるかないか。\
\
それでも、\
**ズボンの裾には、はっきり出ます。**

**どちらが原因、ということはない**\
「背骨が曲がっているから\
骨盤がずれたんですか？\
それとも逆ですか？」\
\
と聞かれることもあります。\
\
答えは、\
**どちらが原因ということはない**、\
です。\
\
背骨と骨盤は、\
お互いに\
影響し合っています。\
座っている時の姿勢、\
仕事中の姿勢も\
関わってきます。

**回数より、角度です**\
「じゃあ、\
硬いほうの脚は\
反対の倍やったら\
いいですか？」\
\
そう聞かれました。\
気持ちは、\
よく分かります。\
\
でも、\
大事なのは\
**回数ではなく、角度**\
です。\
\
小さく20回より、\
**大きく10回。**\
\
もも上げなら、\
できるところまで高く。\
股関節も、\
腰のひねりも、\
動かせる範囲\
いっぱいまで。\
\
固まっているのは、\
**動く範囲が狭くなっているから**\
です。\
狭い範囲の中で\
回数を増やしても、\
広がっていきません。

**正座で、つま先を揃える**\
もう一つ、\
私がよく\
お勧めするのが\
**正座**です。\
\
ポイントは、\
**つま先を重ねずに、揃えること。**\
\
無意識に座ると、\
たいてい\
重なっています。\
\
そのまま\
体を真っ直ぐに起こすと、\
骨盤と背骨が\
真っ直ぐに\
なりやすい。\
\
ずっと座っていなくて\
大丈夫です。\
しびれますから。\
\
崩れてきたら座り直して、\
**同じ場所にかかとが来ているか**を\
確かめる。\
\
リセットとチェックが、\
一度にできます。

**いちばん身近な物差し**\
骨盤が\
同じ位置に戻れば、\
丈も揃ってきます。\
歩きやすさも\
変わってきます。\
\
**ズボンの裾は、毎日見ている、いちばん身近な「物差し」**\
なのかもしれません。\
\
衣替えのついでに、\
一度\
左右を見比べてみてください。

小川
