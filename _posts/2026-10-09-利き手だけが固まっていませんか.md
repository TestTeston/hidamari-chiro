title: 利き手だけが、固まっていませんか

右手だけが、つらい。\
左手は、そうでもない——\
\
そう言われる方が、\
とても増えています。\
\
しかも、\
スポーツで痛めたのではなく、\
**仕事での使いすぎ**です。

**利き手が疲れるのには、理由があります**\
ただ力を使っているから、\
ではありません。\
\
**利き手は、細かい作業を任されています。**\
\
微妙な力加減。\
動きの正確さ。\
\
重いものを持つより、\
**そちらのほうが、よほど疲れます。**\
\
力仕事は\
両手で分け合えますが、\
細かい仕事は\
利き手が一人で\
引き受けています。\
\
毎日、\
何年も。

**疲れは、たまっていきます**\
たまってくると、\
まず\
**動きが悪くなります。**\
\
そのうち、\
指がつる。\
\
朝、\
手がこわばる。\
\
腱鞘炎だと\
言われる。\
\
**急に壊れたわけではありません。**\
\
少しずつ\
積み上がってきたものが、\
形になって\
出てきただけです。

**指だけの問題では、ありません**\
ここが\
大事なところです。\
\
**指・手首・肘・肩・首は、一本の道でつながっています。**\
\
指先で\
ぐっと力を入れれば、\
その力は\
肘を通り、\
肩を通って、\
首まで\
届いています。\
\
実際、\
手をかばっているうちに\
肩まで痛くなった、という方は\
珍しくありません。\
\
腱鞘炎も、\
同じです。\
\
**手だけを見ていても、よくなりません。**

**やることは、手のストレッチです**\
**指も、手首も、たくさん動かしてあげてください。**\
\
**なるべく大きく回す。**\
**できる限り曲げる。**\
\
ゆっくりで構いません。\
先日書いたとおり、\
**勢いはつけないこと。**\
\
ありがたいのは、\
**手首は、座っていても立っていてもできる**ことです。\
\
腕を大きく回すには\
場所がいりますが、\
手首なら\
どこででも回せます。\
\
信号待ちでも。\
お湯が沸くまでの間でも。

**気づいた時に、少しだけ**\
利き手は、\
これからも\
働き続けます。\
\
休ませることは\
できません。\
\
できるのは、\
**使ったぶん、ほどいてあげる**ことだけです。\
\
一日に何度も、\
でなくて構いません。\
\
思い出した時に、\
くるくると\
回してあげてください。

小川
