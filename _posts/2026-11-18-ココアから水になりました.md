患者さんと\
飲み物の話で\
盛り上がったことが\
あります。\
\
話しているうちに、\
**自分の好みが、ずいぶん変わってきた**\
ことに\
気づきました。

**ココアから、水へ**\
就職したばかりの頃は、\
ココアや\
カフェオレを\
よく飲んでいました。\
\
それが\
いつのまにか\
ミルクティーになり、\
ストレートティーになり。\
\
**最近は、買うなら水です。**\
\
甘いものから、\
だんだん\
すっきりしたものへ。\
\
自分で\
決めたわけでは\
ありません。\
気がついたら、\
そうなっていました。

**「ココア、意外とすっきり飲めますよ」**\
その話をしたら、\
患者さんに\
こう言われました。\
\
「ココアって、\
意外と\
すっきり飲めますよ」\
\
**ココアなんて、もう何年飲んでいないんだろう。**\
\
後で\
飲んでみようと\
思いました。

**合わなくなるものもある**\
その患者さんは、\
**以前は平気だったミルクコーヒーで、お腹を下すようになった**\
そうです。\
カフェオレは\
平気なのに。\
\
「何かの素材が\
合わなく\
なったんだろうね」\
\
と言うと、\
\
「そういうのは、\
飲まないほうがいい\
ってことですよね」\
\
と、\
あっさり。\
\
**体の反応を、そのまま受け取る。**\
\
これは\
なかなか\
大事なことだと\
思います。

**好みも、体と一緒に変わる**\
好みが\
変わるのも。\
前は平気だったものが\
合わなくなるのも。\
\
**どちらも、体が変わってきたしるし**\
なのだと思います。\
\
無理に\
昔の好みに\
合わせなくていい。\
\
今の体が\
「これがいい」と\
言うものを、\
選んでいけばいい。\
\
……とは言いつつ、\
久しぶりのココアが\
今の私に\
合うかどうか。\
\
それは\
飲んでみないと\
分かりません。

小川
